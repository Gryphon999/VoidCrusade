## Phase 2 — Resource System

Two resources:
- **Scrip** — gained by holding Void-Nexus capture points (25/sec per point held)
- **Flux** — generated by Power Conduits (buildings)

File `src/systems/ResourceSystem.ts`:

```typescript
export interface Resources {
  scrip: number;
  flux: number;
}

export class ResourceSystem {
  private resources: Record<'player' | 'enemy', Resources>;

  tick(dt: number): void   // called every frame, adds income
  canAfford(owner, cost: Resources): boolean
  spend(owner, cost: Resources): void
  addIncome(owner, type: 'scrip' | 'flux', amount: number): void
  removeIncome(owner, type: 'scrip' | 'flux', amount: number): void
  getResources(owner): Resources
}
```

## Phase 3 — Base Building System

This is the heart of the game. Players click to place buildings on the grid.

### Buildings — Iron Void faction

| ID | Name | Cost | Flux gen | Description |
|----|------|------|----------|-------------|
| `stronghold` | Command Bastion | — | +0 | Starting HQ, spawned at game start. Produces Commander. If destroyed → player loses. |
| `generator` | Flux Conduit | 100 scrip | +10 flux/sec | Power source. Required for most buildings. |
| `barracks` | Assault Barracks | 150 scrip, 50 flux | 0 | Trains infantry squads |
| `mechanis` | Mechanis Bay | 200 scrip, 100 flux | 0 | Trains heavy units |
| `turret` | Void Turret | 75 scrip, 50 flux | 0 | Static defense, auto-attacks enemies in range |
| `relay` | Signal Relay | 100 scrip, 75 flux | 0 | Extends buildable area |
| `research` | Void Foundry | 250 scrip, 150 flux | 0 | Unlocks upgrades |

### Building rules
- Buildings snap to 4×4 tile grid
- Must be placed within 10 tiles of an existing friendly building (or Signal Relay)
- Cannot overlap cliffs or existing buildings
- Show green/red ghost preview while placing
- Each building has HP, can be attacked and destroyed
- Destroyed buildings leave rubble (passable terrain)
- Buildings construct over time (0 → 100% with animation)

### File structure

```
src/buildings/
  BuildingDefs.ts        (data: all building definitions)
  Building.ts            (class: sprite, HP bar, state machine: building/ready/destroyed)
  BuildingSystem.ts      (manages all buildings, placement validation, HP)
  BuildingPlacementUI.ts (ghost preview, click to place, cancel with Escape/RMB)
```

### Visual (procedural)
- Use `Phaser.GameObjects.Graphics` to draw each building as a distinct recognizable shape
- Show HP bar above each building (green → yellow → red)
- Construction animation: alpha 0.3 → 1.0 over build time
- Blue selection ring when clicked

### Squad behavior

File `src/units/Unit.ts` — individual soldier sprite
File `src/units/Squad.ts` — group of Unit instances
File `src/units/UnitSystem.ts` — manages all squads

- Each squad is selected as one entity
- Individual soldiers spread around squad center (formation: 2×3 grid with spacing)
- **Reinforcement**: if squad is below max size and player pays half cost, new soldiers spawn over time
- **Combat**: squads auto-attack nearest enemy in range; projectile sprite flies from attacker to target
- **Death**: when all soldiers in a squad die, squad is removed; each soldier death triggers blood splatter

### Movement

- Click-to-move: right-click on ground = move order
- Right-click on enemy = attack order (move into range, then attack)
- Basic steering: each soldier moves toward squad target, avoids other soldiers (separation force)
- No full pathfinding required — soldiers steer around cliffs with simple obstacle avoidance

### Selection

- Left-click selects one squad
- Drag rectangle to multi-select
- Shift+click to add/remove from selection
- Selected squads show green selection ring
- Selection panel at bottom shows: squad name, HP bar, squad count, action buttons (Reinforce, Move, Attack-move)

```typescript
export class BloodEffect {
  // Emit 8-16 particles per death
  // Each particle: red circle (2-6px radius), random velocity outward
  // Particles decelerate, fade alpha to 0 over 0.4-0.8 seconds
```

## Phase 6 — Void-Nexus Capture Points

The strategic resource mechanic (core of Dark Crusade gameplay).

### Rules
- 5 capture points on each battle map (symmetric: 1 at center, 2 per side)
- Each point generates +25 Scrip/sec to its holder
- **Capturing**: move a squad into the 3×3 tile capture zone
  - Capture bar fills over 5 seconds while squad stays in zone
  - Enemy units in zone contest and push bar backward
  - Once bar reaches 100% → point changes ownership
- Visual: tall obelisk sprite, emits colored aura (blue = player, red = enemy, grey = neutral)
- Aura pulses smoothly with tween
- Mini-map dots change color when captured

File `src/systems/CapturePointSystem.ts`

## Phase 7 — AI Opponent (Null Horde)

File `src/ai/AIController.ts`

The AI controls the Null Horde faction. Three behaviors in priority order:

1. **Build phase** (first 60 seconds): place 2 generators, then barracks-equivalent
2. **Raid phase**: every 30-45 seconds send a wave of crawlers toward nearest player capture point or unit
3. **Rush if winning**: if AI holds 3+ capture points and has 5+ squads, send everything at player Stronghold
4. **Defend**: always keep 2 squads near own Stronghold

AI difficulty (set in `src/config.ts`):
- Easy: 0.5× income rate, 60-second raid interval, no rush
- Normal: 1.0× income rate, 30-second raid interval
- Hard: 1.5× income rate, 20-second raid interval, smarter targeting
